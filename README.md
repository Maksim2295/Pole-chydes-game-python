# 🎡 Поле Чудес на Python! 

Привет! Это мой первый проект на Python — консольная игра «Поле Чудес» в формате **All-in-One** (весь код и база из 100 слов находятся в одном файле `Pole-chudes_v-1-0.py`, без сторонних библиотек).

### ✨ Особенности:
* 🎨 Цветной интерфейс.
* 🔢 Счётчик попыток (5 ошибок).
* 🛑 Команда `СТОП` для выхода.
* 🔄 Команда `ЗАНОВО` для перезапуска.

### 🎮 Как запустить:
1. Установи [Python 3](https://python.org).
2. Скачай файл `Pole-chudes_v-1-0.py` из репозитория [GitHub](https://github.com/Maksim2295/Pole-chydes-game-python).
3. Запусти в терминале:
   ```bash
   python Pole-chudes_v-1-0.py
   ```
