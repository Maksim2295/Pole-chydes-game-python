# 🎡 Поле Чудес на Python! 

Привет! Рад видеть тебя в моём репозитории! 👋

Я только начинаю свой путь в программировании, и это — мой самый первый настоящий проект на Python. Я очень старался сделать игру не просто рабочей, а приятной и удобной для каждого, кто захочет в неё поиграть. 

Игра написана в формате **All-in-One** (всё в одном файле). Это значит, что тебе не нужно скачивать никаких сторонних библиотек через терминал. Весь код, цвета и огромная база из 100 русских слов уже зашиты внутри. Скачал — и сразу играешь!

---

### ✨ Что я реализовал в этой версии:
* 🎨 **Цветной интерфейс:** Никаких унылых серых букв! Всё раскрашено встроенными кодами терминала (зелёный — для побед, красный — для ошибок).
* 🔢 **Счётчик попыток:** У тебя есть ровно 5 попыток на ошибку. Игра честно предупредит, когда ситуация станет критической.
* 🛑 **Кнопка СТОП:** Если нужно срочно бежать, просто напиши `СТОП` в любой момент — игра закроется и покажет твой баланс очков и загаданное слово.
* 🔄 **Команда ЗАНОВО:** Не нужно перезапускать скрипт руками. Напиши `ЗАНОВО` после матча, и игра начнётся с чистой страницы и новым случайным словом!

---

### 🎮 Как запустить игру у себя

Для запуска игры на твоём компьютере должен быть установлен **Python 3**.

1. Если его ещё нет, скачай его с официального сайта: [Скачать Python](https://python.org)
2. Скачай мой файл `pole_chudes.py` из этого репозитория.
3. Открой терминал (или командную строку) в папке с файлом и запусти его командой:
   ```bash
   python pole_chudes.py
   ```
